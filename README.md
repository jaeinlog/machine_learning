# Fish Weight Ridge Regression

Fish Market 데이터로 물고기의 무게를 예측한 회귀 실습입니다.

## 모델

- Mean Baseline
- LinearRegression
- Ridge

## 결과

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Baseline | 329.77 | 381.47 | -0.0231 |
| Ridge | 104.89 | 132.51 | 0.8766 |
| LinearRegression | 103.91 | 129.48 | 0.8821 |
